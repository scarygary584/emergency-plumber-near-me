Build the plan

Four details to organize before an emergency

1

Map shutoffs

Record main, building, unit, fixture, irrigation, and water-heater shutoffs. Label only valves that have been correctly identified.

2

Define access

Keep current gate, lockbox, alarm, tenant-notice, and after-hours access instructions with the property record.

3

Set approval rules

Document who can authorize diagnosis, temporary measures, repair work, and spending when the owner is unavailable.

4

Use one intake checklist

Ask every caller where the water started, where it traveled, what was shut off, and whether another unit is affected.

During the call

Describe the property, not just the symptom

Identify whether the location is a single-family rental, duplex, apartment building, office, retail space, or vacant listing. State the floor, unit, occupancy, affected fixtures, and access limitations.

For a real-estate transaction or vacant property, explain who has authority to approve work and whether utilities are currently on. Never ask an agent, tenant, or visitor to enter an electrically hazardous or sewage-contaminated area.

Request checklist

✓ Property address and unit

✓ On-site contact and callback number

✓ Active water, sewage, or no-water status

✓ Safe shutoff result

✓ Number of affected units or fixtures

✓ Access and authorization details
